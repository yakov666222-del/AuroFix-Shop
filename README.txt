
# AuroFix Shop — גרסת דפדפן (LocalStorage)

קבצים אלו מוכנים להעלאה כפי שהם (תיקייה שלמה) ל‑Cloudflare Pages / Netlify.
- הלוגו נמצא תחת `assets/logo.png` (כבר בפנים).
- כל העמודים כוללים את הלוגו והניווט העליון.
- QR מודפס דרך דף נפרד `qr.html` ומשתמש ב‑Google Chart להפקת QR (אמין ומהיר).

## עיקרי הפונקציונליות
- לוח: KPIs.
- מלאי: הוספה/הפחתה, ייצוא JSON, איפוס.
- טופס תיקון חדש: שמירה ל‑LocalStorage + הפחתת מלאי לפי "חלקים בשימוש".
- תיקונים: רשימה, מחיקה, ו‑QR לכל תיקון.
- QR: עמוד הדפסה ייעודי עם CSS מודפס שמסתיר הכל חוץ מה‑QR.

## הדפסה לבנה בספארי — נפתר
אנחנו מדפיסים מדף נפרד (`qr.html`) עם CSS של `@media print` כך שספארי לא ינסה "לחתוך" קומפוננטים דינמיים.

בהצלחה! 🚀
