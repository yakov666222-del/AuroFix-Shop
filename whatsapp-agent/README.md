# 🤖 יועץ אישי בווטסאפ - YakovPhone

יועץ ועוזר אישי שיושב **בווטסאפ שלך**. כותבים לו בצ'אט "הודעה לעצמי" (הצ'אט עם המספר שלך) ומקבלים תשובה, כמו לדבר עם שותף מנוסה שתמיד זמין.

### היועץ האישי שלך
- **עונה על כל דבר:** מיסים, מע"מ, ביטוח לאומי, הנהלת חשבונות, תמחור, שיווק, עובדים, חוזים, ספקים, תזרים, וגם שאלות כלליות מהחיים
- **מלווה אותך בצמיחה:** מעוסק זעיר, דרך עוסק מורשה ועד חברה בע"מ. מתי לעבור, מה צריך לפתוח, אילו דיווחים ומועדים יש
- **בודק באינטרנט:** תקרות, שיעורי מס ומועדים משתנים כל שנה, אז הוא בודק במקורות רשמיים (gov.il, רשות המסים, ביטוח לאומי) ושולח קישור למקור
- **זוכר אותך:** מה שתספר לו על העסק (סטטוס, מחזור, יעדים, החלטות) נשמר, כך שלא צריך לחזור על עצמך. `!זיכרון` מראה מה הוא זוכר
- **רואה תמונות:** אפשר לצלם קבלה, חשבונית או מכתב מרשות המסים ולשאול עליו
- **תזכורות:** "תזכיר לי ב-15 לחודש לשלם מקדמות"
- **עוזר בווטסאפ:** "מי חיכה לתשובה היום?", "תסכם לי מה משה רצה", "שלח ל-050... שהטלפון מוכן"

> הוא נותן תשובות והמלצות ברורות, אבל בהחלטות גדולות (פתיחת חברה, חוזה משמעותי) הוא יגיד לך מה כדאי לאשר מול רואה חשבון או עורך דין.

### אופציונלי: מענה אוטומטי ללקוחות (כבוי כברירת מחדל)
כותבים `!הפעל`, והסוכן מתחיל לענות ללקוחות שכותבים לך, לפי המידע בקובץ `business.md`:
- מעדכן אותך כשהוא לא יודע מה לענות או כשהלקוח מבקש אותך
- אם ענית ללקוח בעצמך, הוא שותק בצ'אט הזה לשעה
- לא עונה בקבוצות, ומוגבל ל-20 תשובות לשעה בכל צ'אט
- `!כבה` מפסיק את המענה

> 🔒 לקוחות לא יכולים לגרום לסוכן לשלוח הודעות בשמך, לקרוא צ'אטים או לראות את הזיכרון. כל אלה עובדים רק מהצ'אט שלך עם עצמך.

## התקנה (פעם אחת)

1. התקן **Node.js 20 ומעלה** מ-https://nodejs.org
2. פתח טרמינל בתיקייה `whatsapp-agent` והרץ:
   ```bash
   npm install
   cp .env.example .env
   ```
3. ערוך את `.env` והכנס את `ANTHROPIC_API_KEY` (מקבלים ב-https://platform.claude.com, תחת API Keys)
4. ערוך את **`business.md`**: שעות, כתובת ומחירים (חשוב בעיקר אם תפעיל מענה ללקוחות)
5. הפעל:
   ```bash
   npm start
   ```
6. יופיע קוד QR בטרמינל (או בכתובת http://localhost:3000). בטלפון: **ווטסאפ › הגדרות › מכשירים מקושרים › קישור מכשיר** וסרוק.
7. תקבל ב"הודעה לעצמי" את ההודעה "✅ היועץ האישי שלך מחובר". מעכשיו פשוט כותבים לו שם. כדאי להתחיל ב: "היי, אני יעקב, יש לי מעבדת תיקון טלפונים, אני עוסק זעיר. מה אני צריך לדעת?"

החיבור נשמר בתיקייה `data/auth`, אז לא צריך לסרוק שוב בכל הפעלה.

## שיפעל 24/7
הסוכן עונה רק כשהתוכנה רצה. אפשרויות:
- **מחשב שתמיד דלוק** בחנות: `npm install -g pm2`, אחר כך `pm2 start src/index.js --name whatsapp` ואז `pm2 save`
- **שרת בענן** (VPS זול, Railway, Render וכו'): מריצים אותו דבר. מגדירים `QR_PAGE_KEY` ב-`.env` ופותחים `http://<שרת>:3000/?key=<הסיסמה>` כדי לסרוק.
  חשוב: התיקייה `data/` צריכה להישמר בין הפעלות (דיסק קבוע).

## ⚠️ חשוב לדעת
- זה חיבור **לא רשמי** לווטסאפ (כמו WhatsApp Web). ווטסאפ עלולה לחסום מספרים שמשתמשים בבוטים. כשמשתמשים רק ביועץ (המענה ללקוחות כבוי), הוא כותב רק לך, אז הסיכון נמוך מאוד. לשימוש עסקי בהיקף גדול עדיף WhatsApp Business API הרשמי.
- כל הודעה נשלחת ל-Claude API ועולה כסף. בדרך כלל זה כמה אגורות להודעה, ושאלה שדורשת חיפוש באינטרנט עולה קצת יותר.
- הודעות קוליות עדיין לא נתמכות. אפשר להשתמש בהכתבה של המקלדת.
- הנתונים (צ'אטים, הגדרות, תזכורות) נשמרים מקומית בתיקייה `data/`.

## הגדרות (`.env`)
| משתנה | ברירת מחדל | מה זה |
|---|---|---|
| `OWNER_NAME` | יעקב | השם שלך |
| `BUSINESS_NAME` | YakovPhone (יעקב פון) | שם העסק |
| `TAKEOVER_MINUTES` | 60 | כמה זמן הסוכן שותק אחרי שענית בעצמך |
| `DEBOUNCE_SECONDS` | 6 | המתנה לפני תשובה |
| `MAX_REPLIES_PER_HOUR` | 20 | הגבלה לכל צ'אט |
| `CLAUDE_MODEL` | claude-opus-5-5 | המודל |
| `OWNER_EFFORT` | high | כמה לעומק היועץ חושב (low/medium/high) |
| `QR_PAGE_KEY` | (ריק) | סיסמה לעמוד ה-QR |
