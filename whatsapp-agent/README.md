# 🤖 סוכן אישי לווטסאפ - AuroFix

סוכן שמתחבר **לווטסאפ האישי שלך** (כמו WhatsApp Web, בסריקת QR) ועובד בשבילך:

### מה הוא עושה
**מול לקוחות (אוטומטי):**
- עונה ללקוחות בעברית, קצר וטבעי, לפי המידע שכתוב בקובץ `business.md` (שעות, מחירים, שירותים)
- רואה תמונות (למשל של מסך שבור)
- כשהוא לא יודע או שהלקוח מבקש אותך, הוא שולח לך התראה בצ'אט "הודעה לעצמי"
- **ענית בעצמך ללקוח?** הסוכן מפסיק לענות בצ'אט הזה לשעה (ניתן לשינוי)
- אוסף כמה הודעות רצופות ועונה עליהן בתשובה אחת
- לא עונה בקבוצות (אלא אם מפעילים), לא עונה לסטטוסים, ומוגבל ל-20 תשובות לשעה בכל צ'אט

**מולך (בצ'אט "הודעה לעצמי" בטלפון):**
- "מי חיכה לתשובה היום?"
- "תסכם לי מה משה רצה"
- "שלח ל-0501234567 שהטלפון מוכן לאיסוף"
- "תזכיר לי מחר ב-9 להזמין מסכים"
- פקודות מהירות: `!כבה` `!הפעל` `!סטטוס` `!השתק משה` `!שחרר משה` `!עזרה`

> 🔒 לקוחות לא יכולים לגרום לסוכן לשלוח הודעות בשמך: לכלים של שליחת הודעות, קריאת צ'אטים ותזכורות יש גישה רק מהצ'אט שלך עם עצמך.

## התקנה (פעם אחת)

1. התקן **Node.js 20 ומעלה** מ-https://nodejs.org
2. פתח טרמינל בתיקייה `whatsapp-agent` והרץ:
   ```bash
   npm install
   cp .env.example .env
   ```
3. ערוך את `.env` והכנס את `ANTHROPIC_API_KEY` (מקבלים ב-https://platform.claude.com, תחת API Keys)
4. ערוך את **`business.md`**: שעות, כתובת ומחירים. זה כל מה שהסוכן יודע.
5. הפעל:
   ```bash
   npm start
   ```
6. יופיע קוד QR בטרמינל (או בכתובת http://localhost:3000). בטלפון: **ווטסאפ › הגדרות › מכשירים מקושרים › קישור מכשיר** וסרוק.
7. תקבל ב"הודעה לעצמי" את ההודעה "✅ הסוכן מחובר ופועל". זהו!

החיבור נשמר בתיקייה `data/auth`, אז לא צריך לסרוק שוב בכל הפעלה.

## שיפעל 24/7
הסוכן עונה רק כשהתוכנה רצה. אפשרויות:
- **מחשב שתמיד דלוק** בחנות: `npm install -g pm2`, אחר כך `pm2 start src/index.js --name whatsapp` ואז `pm2 save`
- **שרת בענן** (VPS זול, Railway, Render וכו'): מריצים אותו דבר. מגדירים `QR_PAGE_KEY` ב-`.env` ופותחים `http://<שרת>:3000/?key=<הסיסמה>` כדי לסרוק.
  חשוב: התיקייה `data/` צריכה להישמר בין הפעלות (דיסק קבוע).

## ⚠️ חשוב לדעת
- זה חיבור **לא רשמי** לווטסאפ (כמו WhatsApp Web). ווטסאפ עלולה לחסום מספרים שמשתמשים בבוטים, בעיקר אם הם שולחים הרבה הודעות או ספאם. הסוכן עונה רק למי שכתב לך, וכך הסיכון נמוך, אבל הוא לא אפס. לשימוש עסקי בהיקף גדול עדיף WhatsApp Business API הרשמי.
- כל הודעה שהסוכן עונה עליה נשלחת ל-Claude API ועולה כסף (בדרך כלל אגורות בודדות להודעה).
- הנתונים (צ'אטים, הגדרות, תזכורות) נשמרים מקומית בתיקייה `data/`.

## הגדרות (`.env`)
| משתנה | ברירת מחדל | מה זה |
|---|---|---|
| `OWNER_NAME` | יעקב | השם שלך |
| `BUSINESS_NAME` | AuroFix | שם העסק |
| `TAKEOVER_MINUTES` | 60 | כמה זמן הסוכן שותק אחרי שענית בעצמך |
| `DEBOUNCE_SECONDS` | 6 | המתנה לפני תשובה |
| `MAX_REPLIES_PER_HOUR` | 20 | הגבלה לכל צ'אט |
| `CLAUDE_MODEL` | claude-opus-5-5 | המודל |
| `QR_PAGE_KEY` | (ריק) | סיסמה לעמוד ה-QR |
