# קיצור "עוזר" לאייפון: הוראות בשפה חופשית

אומרים "היי סירי, עוזר" (או לוחצים על הקיצור), אומרים מה לעשות, והאייפון מבצע.
הקיצור באייפון קטן ופשוט: הוא שולח את ההוראה לשרת היועץ (`POST /shortcut`), מקבל פעולה ומבצע אותה.
ההבנה של העברית נעשית בשרת (`advisor/src/shortcut.js`), כך שאפשר לשפר אותה בלי לגעת באייפון.

## מה אפשר להגיד

| דוגמה | מה קורה |
|---|---|
| "פתח וואטסאפ", "תפתח את הוויז", "פתח יומן" | נפתחת האפליקציה |
| "פתח את המעבדה", "פתח את מערכת התיקונים" | נפתחת מערכת המעבדה |
| "פתח את היועץ" | נפתח הצ'אט עם היועץ |
| "הפעל קיצור סגירת יום" | מופעל הקיצור "סגירת יום" |
| "תזכיר לי מחר ב-10 להתקשר למשה" | תזכורת באפליקציית התזכורות, עם התראה |
| "תזכיר לי בעוד שעה לבדוק את הסוללה" | תזכורת בעוד שעה |
| "תזכיר לי ביום חמישי בבוקר לשלם לספק" | תזכורת ליום חמישי ב-9:00 |
| "קבע פגישה עם רואה החשבון מחרתיים ב-11 וחצי" | אירוע ביומן (שעה אחת) |
| "תוסיף ליומן ספק מסכים ב-1/12 ב-16:00 לחצי שעה" | אירוע של חצי שעה |
| כל דבר אחר: "כמה מסכים של אייפון 13 יש במלאי?", "מה מצב התיקון של משה?" | השאלה עוברת ליועץ, שמחובר למעבדה, והתשובה מוקראת |

אפליקציות שמוכרות: וואטסאפ, וויז, מפות, טלפון, הודעות, מייל, ג'ימייל, יומן, תזכורות, פתקים, תמונות, שעון, מוזיקה, ספוטיפיי, יוטיוב, אינסטגרם, פייסבוק, טלגרם, כרום, ספארי, אפ סטור, הגדרות, קיצורים, קבצים, נושן.
אפליקציה אחרת (למשל "פתח מחשבון"): הקיצור מפעיל קיצור בשם "פתח מחשבון". יוצרים אותו פעם אחת עם פעולה אחת, "פתח אפליקציה" ← מחשבון.

**בטיחות:** הקיצור לא מוחק, לא משלם ולא שולח הודעות בעצמו. שינויים במלאי דרך היועץ עדיין דורשים "כן" ממך, כמו בווטסאפ.

## התקנה (פעם אחת, כ-10 דקות)

לפני שמתחילים צריך את **כתובת היועץ** ואת **המפתח**. שניהם מופיעים בכתובת של אפליקציית היועץ שבמסך הבית: `https://<כתובת-היועץ>/chat?key=<המפתח>`.
כתובת הקיצור היא: `https://<כתובת-היועץ>/shortcut?key=<המפתח>`

פותחים את אפליקציית **קיצורים** ← **+** (קיצור חדש) ← קוראים לו **עוזר**. מוסיפים את הפעולות לפי הסדר.
(בסוגריים מופיע השם באנגלית, למקרה שהאייפון באנגלית או שהחיפוש בעברית לא מוצא.)

1. **בקש קלט** (Ask for Input)
   - סוג: טקסט. שאלה: `מה לעשות?`
2. **קבל תוכן של URL** (Get Contents of URL)
   - URL: כתובת הקיצור מלמעלה.
   - לוחצים על החץ ←: שיטה **POST**, גוף הבקשה **JSON**.
   - מוסיפים שדה: סוג **טקסט**, מפתח `text`, ערך: המשתנה **קלט שסופק** (Provided Input).
3. **קבל ערך מילון** (Get Dictionary Value): קבל **ערך** עבור `speak` ב**תוכן של URL**.
4. **הגדר משתנה** (Set Variable): שם `תשובה`, ערך: **ערך מילון**.
5. **קבל ערך מילון**: ערך עבור `url` ב**תוכן של URL**.
   חשוב: לוחצים על המילה שבסוף הפעולה ומוודאים שהקלט הוא **תוכן של URL**, ולא התוצאה של הפעולה הקודמת. כך גם בכל פעולת "קבל ערך מילון" שבהמשך.
6. **אם** (If): **ערך מילון** ← **יש ערך כלשהו** (has any value)
   - בתוך ה"אם": **פתח כתובות URL** (Open URLs) ← **ערך מילון**.
   - מוחקים את "אחרת" (Otherwise) אם נוסף, או משאירים אותו ריק.
7. **קבל ערך מילון**: ערך עבור `action` ב**תוכן של URL** ← **הגדר משתנה** `פעולה`.
8. **אם** `פעולה` **הוא** `reminder`:
   - **קבל ערך מילון** `title` מ**תוכן של URL** ← **הגדר משתנה** `כותרת`.
   - **קבל ערך מילון** `due` מ**תוכן של URL**.
   - **אם** **ערך מילון** **יש ערך כלשהו**:
     - **הוסף תזכורת חדשה** (Add New Reminder): כותרת = `כותרת`. מסמנים **התראה** ← **ביום ובשעה**, והתאריך = **ערך מילון**.
   - **אחרת**:
     - **הוסף תזכורת חדשה**: כותרת = `כותרת`, בלי התראה.
9. **אם** `פעולה` **הוא** `event`:
   - **קבל ערך מילון** `title` ← הגדר משתנה `כותרת`.
   - **קבל ערך מילון** `start` ← הגדר משתנה `התחלה`.
   - **קבל ערך מילון** `end` ← הגדר משתנה `סיום`.
   - **הוסף אירוע חדש** (Add New Event): כותרת = `כותרת`, התחלה = `התחלה`, סיום = `סיום`, יומן: ברירת המחדל.
     בהגדרות הפעולה מכבים את **הצג בעת הפעלה**, כדי שהאירוע יתווסף בלי לשאול.
10. **הצג תוצאה** (Show Result) ← `תשובה`. כשמפעילים דרך סירי, התשובה מוקראת בקול.

לסיום לוחצים **סיום**.

### הפעלה מהירה
- **סירי:** "היי סירי, עוזר".
- **כפתור הפעולה** (אייפון 15 Pro ומעלה): הגדרות ← כפתור פעולה ← קיצור ← עוזר.
- **הקשה כפולה על גב הטלפון:** הגדרות ← נגישות ← מגע ← הקשה בגב ← הקשה כפולה ← עוזר.
- **מסך הבית:** בקיצור ← שיתוף ← הוסף למסך הבית.

### הפעלה ראשונה
באייפון יופיעו שאלות הרשאה: גישה לכתובת היועץ, לתזכורות וליומן. עונים **אפשר תמיד** (Always Allow), כדי שבפעם הבאה הקיצור ירוץ בלי לשאול.

## בדיקה אחרי ההתקנה
1. "פתח וואטסאפ": וואטסאפ צריך להיפתח.
2. "תזכיר לי בעוד 5 דקות לבדוק את העוזר": באפליקציית התזכורות מופיעה תזכורת, ואחרי 5 דקות מגיעה התראה.
3. "קבע פגישת בדיקה מחר ב-12": ביומן מופיע אירוע מחר בין 12:00 ל-13:00. אחרי הבדיקה מוחקים אותו ידנית.
4. "מה יש במלאי?": מתקבלת תשובה מהיועץ.

## אוטומציות אישיות (רשות)
אפליקציית קיצורים ← **אוטומציה** ← **+**. לכל אוטומציה בוחרים **הפעל מיד**:
- **הגעה למעבדה** (מיקום) ← פתח כתובות URL ← כתובת המעבדה.
- **שעה 20:00 בימים א'-ה'** ← הפעל קיצור "עוזר" עם הקלט "מה התיקונים שמחכים למחר?". לשם כך מחליפים בשלב 1 את "בקש קלט" ב"אם קלט הקיצור ריק ← בקש קלט".

## מעבר לשרת אחר (Railway)
אם כתובת היועץ משתנה, מעדכנים רק את ה-URL בשלב 2 של הקיצור. נקודת הקצה `/shortcut` כבר נמצאת בקוד שבמאגר.
